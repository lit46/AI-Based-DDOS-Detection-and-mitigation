# Adaptive AI-Based DDoS Detection and Mitigation in Software Defined Networks

BCSE497J Project-I, VIT Vellore (SCOPE). Aritra Dubey (23BCI0097), Nupoor Atul Mahajan (23BCE0040). Guide: Dr. Manikandan G.

This repository holds the code and saved results behind every table in the report and the IEEE paper.

* `cv_study/`   offline feature-selection study (selectors F0, CR, P1-P4, RA_Consensus and baselines; grouped CV, holdout, Hasan et al. test)
* `live_loop/`  Floodlight closed loop (detector, Mininet topology, evaluator, trained models)
* `results/`    saved outputs, so each table can be checked without re-running anything
* `docs/`       frozen protocols (PROTOCOL_B, PROTOCOL_C)
